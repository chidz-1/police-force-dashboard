## Development Workflow

**ALWAYS** follow the steps of the following development workflow (for every feature/fix or test):

1. **Document** - Document the feature in @context/current-feature.md after being told what feature to work on
2. **Branch** - Create new branch for feature, fix, etc
3. **Implement** - Implement the feature/fix that is present in the @context/current-feature.md
4. **Test** - Verify it works in the browser. Implement unit testing later. Run `npm run build` and fix any errors
5. **Iterate** - Iterate and change things if needed
6. **Commit** - Only after build passes and everything works
7. **Merge** - Merge to main
8. **Delete Branch** - Delete branch after merge
9. **Review** - Review AI-generated code periodically and on demand.
10. **Due diligence** - Mark as completed in @context/current-feature.md and update it's history
