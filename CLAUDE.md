This application serves as a dashboard to visualize publicly available stop and search data.

## Prerequisites

- familiarize yourself with the contents of @AGENTS.md

## Script commands

- start development server: `npm run dev`
- start production server: `npm run start`
- lint the application: `npm run lint`
- format the application: `npm run format`
- perform Typescript static type check: `npm run typecheck`
